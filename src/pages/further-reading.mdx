# Further reading

Every link below was checked to make sure it resolves and actually
matches its description before going on this page.

### The attacks

- Jo Van Bulck et al., ["Foreshadow: Extracting the Keys to the Intel SGX
  Kingdom with Transient Out-of-Order
  Execution"](https://foreshadowattack.eu/) (USENIX Security 2018, pp.
  991–1008). The project page links the full paper, the CVE records, and
  the author list across all four institutions involved.
- Kit Murdock et al., ["Plundervolt: Software-based Fault Injection
  Attacks against Intel SGX"](https://plundervolt.com/) (IEEE S&P 2020,
  pp. 1466–1482). The project page links the full paper, proof-of-concept
  code, and Intel's security advisory.

### Official hardware documentation

- [Intel Software Guard Extensions (SGX)](https://www.intel.com/content/www/us/en/developer/tools/software-guard-extensions/overview.html)
  — Intel's own developer documentation hub.
- [Arm TrustZone for AArch64](https://developer.arm.com/documentation/102418/latest/)
  — Arm's official architecture learning path.
- [AMD Secure Encrypted Virtualization (SEV)](https://www.amd.com/en/developer/sev.html)
  — AMD's official developer page.
